# Financial Metrics ETL & UI

## Overview
An automated Extract, Transform, Load (ETL) pipeline designed for financial consolidation. It ingests market data, applies rigorous cleaning algorithms using Pandas, and serves a minimalist, glass-themed interactive dashboard.

## Tech Stack
- **Data Manipulation:** Python, Pandas, NumPy.
- **Frontend:** Streamlit (Custom Acrylic CSS).
- **Automation:** Scheduled execution ready.

## Installation
```bash
pip install -r requirements.txt
streamlit run financial_etl.py
